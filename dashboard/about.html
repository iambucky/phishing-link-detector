About System

Deep Learning Based Phishing Detection System

PhishGuard AI is an intelligent security system designed to detect phishing links from social media and email communication using Artificial Neural Network (ANN).

The system analyses URL-based features and classifies links as either legitimate or phishing using a trained deep learning model.

System Features

🔍 URL Analysis

The system examines different URL characteristics such as length, special characters, domain details, and suspicious patterns.

🧠 Deep Learning Model

Artificial Neural Network (ANN) is used for training and prediction of phishing and legitimate URLs.

📊 Performance Monitoring

The dashboard provides accuracy, precision, recall, and F1-score information for model evaluation.

🛡 Security Protection

Helps users identify malicious links and reduces the risk of phishing attacks through early detection.

Technology Stack

Frontend

HTML5, CSS3, JavaScript and responsive dashboard components.

Backend

Python-based processing with machine learning integration.

Machine Learning

TensorFlow, Keras, Scikit-Learn and Artificial Neural Network algorithms.

Dataset

Phishing URL dataset containing legitimate and malicious website samples.

Model Information

Artificial Neural Network (ANN)

The phishing detection model is developed using an Artificial Neural Network approach. The model learns patterns from URL features and predicts whether a URL is safe or suspicious.

Training Dataset

Phishing URL Dataset

Data Split

80% Training and 20% Testing

Evaluation Metrics

Accuracy, Precision, Recall and F1-Score

Learning Approach

Supervised Deep Learning Classification

Project Information

PhishGuard AI Dashboard

This project is developed as part of the academic research work on Deep Learning-Based Detection of Phishing Links in Social Media and Email Communication.

The objective of this system is to provide an efficient and automated approach for identifying phishing URLs using artificial intelligence techniques.
